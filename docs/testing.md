# 验证指南

当前可运行的验证覆盖文档结构、链接、篇幅和空白错误，不代表产品行为已经实现或通过验证。

## 文档检查

在仓库根目录使用 Python 3.10 或更高版本运行；检查脚本只依赖标准库和 Git，不需要下载依赖：

```bash
python3 scripts/validate_project_docs.py
```

检查工作区和暂存区的空白错误：

```bash
git diff --check
git diff --cached --check
```

检查脚本来自 `doc-standards` 技能的文档验证器，初始化时原样引入。它读取 `scripts/doc-budgets.manifest.json`，检查文档预算、本地链接、标题锚点及源码中的文档引用；错误时返回非零退出码。

## 产品验证边界

仓库尚无产品测试或 wheel 构建入口。第一阶段的验证目标见[路线图](roadmap.md)。临时探针不是产品验收证据，也不替代对正式发布产物的验证。

产品验证命令随实现加入本页。对离线能力的声明必须区分预先准备依赖与实际运行；对远端能力的声明必须有对应环境中的证据，不能由本地文件替身推导。
